## Integration tests

The integration tests (`AppIntegrationTest`) run the report methods against the real world database. To run them, start the database with `docker compose up -d --build db`, wait about a minute for it to load, then run `AppIntegrationTest` in IntelliJ. All 30 should pass. More detail, including the bugs they found, is in [docs/integration-tests.md](docs/integration-tests.md).
